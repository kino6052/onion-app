# My Bun Project

## Overview

This project is built using Bun and serves as a template for TypeScript applications. It includes a basic structure with an entry point and type definitions.

## Project Structure

```
my-bun-project
├── src
│   ├── index.ts          # Entry point of the application
│   └── types
│       └── index.ts      # Type definitions and interfaces
├── bunfig.toml           # Bun configuration file
├── package.json          # npm configuration file
└── README.md             # Project documentation
```

## Installation

To get started with this project, follow these steps:

1. Clone the repository:

   ```
   git clone <repository-url>
   cd my-bun-project
   ```

2. Install dependencies:
   ```
   bun install
   ```

## Usage

To run the application, use the following command:

```
bun run src/index.ts
```

Add .env file to include your GITHUB_TOKEN variable
